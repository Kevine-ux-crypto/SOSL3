Q1
Student Grade Calculator
Functions Arrays Objects
EASY
📌 You are managing scores for students in a class. Each student has a name and an array of test scores.
  • Create an array of student objects. Each object must have a name (string) and a scores (array of numbers, e.g., 3 scores).
  • Write a function calculateAverage(scores) that takes an array of numbers and returns the average.
  • Write a function getGrade(average) that returns "A" (≥80), "B" (≥70), "C" (≥60), or "F" (below 60) using a conditional statement.
  • Use forEach to loop through each student, call both functions, and print: Alice → Average: 78 → Grade: C.
💡 Hint: Use reduce() inside calculateAverage to sum the scores.
Q2
Product Inventory Manager
Arrays Objects Functions
EASY
📌 A small shop keeps a list of products. Each product has a name, price, and quantity in stock.
  • Create an array of at least 5 product objects with properties: name, price, quantity.
  • Write a function getTotalValue(products) that returns the total stock value (price × quantity for each product, summed).
  • Write a function findCheapest(products) that returns the product object with the lowest price using reduce().
  • Write a function filterAffordable(products, budget) that returns products whose price is ≤ the given budget using filter().
  • Print the results of all three functions to the console.
Q3
Word Frequency Counter using Map
Maps Functions Arrays
MEDIUM
📌 A teacher wants to analyse how often each word appears in a paragraph of text.
  • Write a function countWords(text) that takes a string, splits it into words (use .split(" ")), and uses a Map to count how many times each word appears.
  • The function should return the Map of word counts.
  • Write another function getMostFrequent(wordMap) that loops through the Map and returns the word that appears the most times.
  • Test your functions with the sentence: "the cat sat on the mat the cat" and print both the full Map and the most frequent word.
💡 Hint: Use map.set(key, value) and map.get(key). Loop using for...of map.entries().
Q4
Unique Visitors Tracker using Set
Sets Functions Arrays
MEDIUM
📌 A website logs every visit. The same user can visit multiple times. You need to count only unique visitors.
  • Given this visits array: ["Alice","Bob","Alice","Charlie","Bob","Alice","Diana"], write a function getUniqueVisitors(visits) that uses a Set to find unique names.
  • Return the number of unique visitors and the list of their names as an array (use Array.from() or spread operator on the Set).
  • Write a second function getVisitCount(visits, name) that uses filter() to count how many times a given name appears in the visits array.
  • Print: "Total unique visitors: 4", then list each unique visitor's name and visit count.
Q5
Library Book System
Objects Functions Arrays Maps
MEDIUM
📌 A school library needs to track its book collection and which books are borrowed.
  • Create an array of book objects: { title, author, genre, available } (at least 6 books, some with available: false).
  • Write a function getAvailableBooks(books) using filter() that returns only available books.
  • Write a function groupByGenre(books) that uses a Map to group books by genre. The Map keys should be genre names and values should be arrays of book titles.
  • Write an arrow function borrowBook = (books, title) => that finds the book with the given title, sets its available to false, and returns a confirmation message. If the book isn't found or is unavailable, return an error message.
  • Display the genre map using for...of.
💡 Hint: Use find() to locate a specific book by title.
Q6
Friends Tag Deduplicator using Set
Sets Arrays Functions
EASY
📌 A social app allows users to add interest tags to their profile, but duplicates keep being added by mistake.
  • Given this tags array: ["music","sports","music","art","coding","sports","coding","travel"], write a function cleanTags(tags) that removes all duplicates and returns a sorted, clean array of unique tags.
  • Use a Set to handle deduplication, then convert back to an array and sort alphabetically.
  • Write a function commonTags(tagsA, tagsB) that finds the tags two users have in common. Use two Sets and check intersection.
  • Test with a second user's tags: ["art","gaming","music","travel","coding"] and print the common tags.
Q7
Phonebook using Map
Maps Functions Objects
MEDIUM
📌 Build a basic phonebook application using a Map to store and manage contacts.
  • Create a Map called phonebook. Each key is a contact name (string) and the value is an object: { phone, email }.
  • Write a function addContact(name, phone, email) that adds or updates a contact. If the contact already exists, print "Contact updated", else print "Contact added".
  • Write a function findContact(name) that retrieves a contact by name. If not found, return "Contact not found".
  • Write a function deleteContact(name) that removes a contact. Print a confirmation or "Contact not found".
  • Write a function listAllContacts() that prints all contacts in the format: Name → phone: ... | email: ...
  • Test all four functions with at least 3 contacts.

Q8
Student Management Mini-App (HTML + JS)
Arrays Objects Functions
MEDIUM
📌 Build a simple web page where a teacher can add students and view their class list dynamically.
  • Create an HTML page with a form: fields for student name, age, and class, plus an "Add Student" button.
  • In your JavaScript file, maintain a students array. Each student added is pushed as an object: { name, age, class }.
  • Write a function renderStudents() that reads the array and updates a <ul> in the DOM, showing each student's details.
  • Add a "Remove" button for each student in the list. Clicking it should remove that student from the array (use splice() or filter()) and call renderStudents() again.
  • Validate the form: name and class must not be empty; age must be a number between 10 and 25. Show an error message if validation fails.
💡 Hint: Use document.getElementById() to get input values and innerHTML to update the list.
Q9
Shopping Cart with Map
Maps Functions Objects Arrays
HARD
📌 Build a shopping cart feature for an e-commerce project page. Products are listed on the page and users can add them to a cart.
  • Define an array of at least 5 product objects: { id, name, price }. Render them as cards on the page using DOM manipulation.
  • Use a Map as the cart (key = product id, value = { name, price, quantity }). When the user clicks "Add to Cart" on a product, increase the quantity if it already exists in the Map, otherwise add it.
  • Write a function renderCart() that displays all cart items in a sidebar, showing name, quantity, unit price, and subtotal per item.
  • Write a function getCartTotal(cart) that iterates the Map and returns the grand total.
  • Add a "Remove" button per cart item that deletes it from the Map and updates the display. Display the total at the bottom of the cart.
💡 Hint: Use map.has(id) before deciding to add or update. Use map.delete(id) to remove.
Q10
Quiz App with Score Tracking
Arrays Objects Functions Sets
HARD
📌 Build an interactive multiple-choice quiz as your project. Questions are stored in an array; the user answers each one and sees their final score.
  • Create an array of at least 5 question objects: { question, options: [], answer } where options is an array of 4 strings and answer is the correct option.
  • Use a Set called answeredQuestions to track which question indices have been answered (preventing re-answering).
  • Write a function renderQuestion(index) that displays the current question and its options as radio buttons on the page.
  • Write a function submitAnswer(index, selected) that checks the answer, adds the index to the Set, increments a score variable if correct, and shows "Correct ✓" or "Wrong ✗" feedback.
  • Write a function showResults() that displays the final score (e.g. "You scored 4 out of 5") and lists which questions were answered correctly using the Set.
  • Add a "Next" button to navigate through questions, and a "Submit Quiz" button at the end.
Q11
Employee Directory with Search & Filter
Arrays Objects Functions Maps
HARD
📌 Build a project page for a company employee directory with search and department filtering.
  • Create an array of at least 8 employee objects: { id, name, role, department, salary }.
  • Write a function searchEmployees(query) that uses filter() to return employees whose name or role includes the search query (case-insensitive). Render the results in the DOM.
  • Use a Map to group employees by department. Write groupByDepartment(employees) and render a dropdown of department names. When a department is selected, show only its employees.
  • Write an arrow function getSalarySummary = (employees) => that returns an object with highest, lowest, and average salary values using reduce() and Math.max/min.
  • Display the salary summary on the page. Add an "Export List" button that uses map() to convert the filtered employees to a comma-separated string and displays it in a <textarea>.
